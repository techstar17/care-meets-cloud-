# Care meets the cloud — Festus Onadeko

A personal portfolio connecting Festus's Dentistry studies, interest in technology for healthcare, and Cloud/DevOps learning projects.

## Open on your laptop

1. Extract the whole ZIP with **Extract All**.
2. Open `index.html` inside the extracted folder.
3. Keep `styles.css`, `script.js`, and `assets` beside `index.html`.

No installation, account, API key, internet fonts, or build command is needed for the local preview.

## Creative feature

**Two worlds. One direction.** Visitors use a slider or three perspective buttons to explore Dentistry, the connection to healthcare technology, and the AWS video that sparked an interest in cloud computing. The illustration changes emphasis alongside the story. A visible hint introduces the feature. Keyboard users can focus the slider and use arrow keys, Home, or End. Normal portfolio navigation is always available.

The project descriptions expand with the **What I worked on** controls.

## Portrait

The original supplied JPEG is included without regenerating the face. CSS blends its white background into the page and fades the bottom edge. The source is 200 × 200 pixels, so a higher-resolution copy would improve sharpness at larger display sizes. Replace `assets/festus.jpg` with a higher-resolution version of the same white-background portrait if available.
